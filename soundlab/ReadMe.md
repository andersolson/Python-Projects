# Example Binaural Beat Tone Pairs for Focus
Focus is generally associated with Beta (13–20 Hz) or low Gamma (30–40 Hz) activity.
To generate a binaural beat, simply keep the difference equal to the target brainwave frequency.

## 1. Mild Focus / Studying (Beta ~14 Hz)
**Left ear:** 220 Hz  
**Right ear:** 234 Hz  
**Beat frequency:** *14 Hz*  
**Good for:** steady concentration, reading, coding, light analytical work.

## 2. Strong Focus / Productivity (Beta ~18 Hz)
**Left ear:** 240 Hz  
**Right ear:** 258 Hz  
**Beat frequency:** *18 Hz*  
Good for: analytical tasks, problem‑solving, GIS data modeling, or detailed work.  

## 3. High-Focus / Intense Concentration (Low Gamma ~32 Hz)
**Left ear:** 400 Hz  
**Right ear:** 432 Hz  
**Beat frequency:** *32 Hz*  
**Good for:** flow-state work, deep focus, time‑critical projects.  

## 4. Clean, Comfortable Listening Pair (Beta ~15 Hz)
**Left ear:** 300 Hz  
**Right ear:** 315 Hz  
**Beat frequency:** *15 Hz* 
This pair uses equal-tempered intervals and is very “easy” for long sessions.  

## 5. High Clarity / Mental Sharpness (Gamma ~40 Hz)
**Left ear:** 500 Hz  
**Right ear:** 540 Hz  
**Beat frequency:** *40 Hz* 
This is an upper-range gamma beat, often used for maximum cognitive activation.
